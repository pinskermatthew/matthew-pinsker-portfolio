# matthew-pinsker-portfolio

Source for [matthewpinsker.com](https://matthewpinsker.com), the technical writing portfolio of Matthew Pinsker.

The site is built with [Astro](https://astro.build) and maintained in collaboration with [Claude Code](https://claude.com/claude-code). All content lives in validated YAML files, and routine updates run through project skills.

## Where to look

- [CLAUDE.md](CLAUDE.md): how AI agents work in this repo, including the rules they follow
- [.claude/skills/](.claude/skills/): reusable skills for maintaining the site
- [docs/PLAN.md](docs/PLAN.md): the project plan and status
- [docs/decisions.md](docs/decisions.md): key decisions and why they were made
- [docs/style-guide.md](docs/style-guide.md): the site's voice and style rules

## Run locally

Requires Node.js 22.12 or later.

```sh
npm install
npm run dev
```
